# ITEMX CODEX 2.5.1

원장(채팅 변수)이 덜 커지도록 다듬은 버전입니다. 기록 형식은 2.5.0과 호환됩니다.

## 바뀐 점

- 카드마다 고정해 두는 표시 내용을, 사건과 달라진 부분만 저장합니다. 카드 1장당 저장량이 약 절반으로 줄었습니다. 화면은 그대로입니다.
- `설정 → 저장 공간 → 저장 공간 정리`를 다시 넣었습니다.
  - 리롤·삭제로 본문에서 사라진 카드 기록과 지워진 메시지의 보조 출력 기록을 지웁니다.
  - 최신 턴에서 만든 기록은 남깁니다. 리롤 후보로 다시 넘겨볼 수 있기 때문입니다.
  - 채팅 전체를 불러온 상태에서만 됩니다. 안내가 뜨면 맨 위까지 스크롤한 뒤 다시 누르세요.
  - 기존 카드도 이때 새 저장 형식으로 바뀝니다.

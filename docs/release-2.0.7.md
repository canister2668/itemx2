# ITEMX CODEX 2.0.7

2.0.6에서 확인하고도 남겨 둔 아이템·조우 보조 검사 중복 문제를 수정했습니다. `누락 시`와 `항상 검토` 모두에 적용됩니다.

## 수정 내용

- 보조가 같은 이름에 새 ID를 붙였을 때 전체 저장 기록을 확인합니다. 명시된 분류·속성·수치 등이 충돌하지 않는 유일한 기존 대상의 ID를 재사용합니다.
- 같은 응답의 후속 패치도 재사용한 ID로 연결합니다. 동일한 현재 상태를 다시 반환하면 새 이벤트와 채팅 저장을 생략합니다.
- 현재 출력에 이미 기록된 동일 소비·획득·교전 패치를 보조가 다시 실행하지 않게 합니다. 다음 출력에서 실제로 다시 일어난 사건에는 이전 출력의 차단 기록을 적용하지 않습니다.
- 본문 사이에 같은 ID·같은 상태가 반복되어도 카드·배너를 다시 표시하지 않습니다. 저장된 사건 원장은 삭제하지 않으며 실제 상태 변화는 보존합니다.
- 기존 항목의 부분 감정이 변화 없는 결과라도 필요한 1회 보완은 유지합니다. 성공한 보완 패치만 최종 저장에 반영합니다.

## 보존 범위와 제한

- 명시적으로 별개 대상인 문맥, 서로 다른 명시 수치·분류, 여러 기존 후보가 있어 식별이 모호한 경우에는 무조건 이름만으로 합치지 않습니다.
- 이미 별도 ID로 저장된 중복 기록을 임의로 삭제하지 않습니다. 서로 다른 이름·번역명까지 완벽하게 의미 판별하는 기능은 아닙니다.
- 기존 마커 형식과 replay는 유지합니다. 아이템·스킬·조우 이펙트, 파티클 수, 저장소 및 클릭 구조는 변경하지 않았습니다.
- 중복 대조는 로컬에서 수행하며 추가 모델 호출이나 프롬프트 토큰을 요구하지 않습니다.

2.0.6 설치본에서도 업데이트를 받을 수 있도록 버전을 2.0.7로 올렸습니다.

# ITEMX CODEX 2.0.15

2.0.14에서 본문 조우 초상을 추가하면서 표시 훅이 캐릭터·채팅·모듈·이미지 조회를 기다리게 된 경로를 제거했습니다. 보조 복구 후 다수의 메시지가 다시 그려질 때 중복 조회와 무기한 대기로 화면이 멈출 수 있었습니다.

- 본문 표시 훅은 캐시만 읽고 동기적으로 반환합니다. 표시 중 호스트 API 조회나 저장을 수행하지 않습니다.
- 초상 준비는 메인 출력·보조 복구·상태 재구축 경로에서 수행하며, 같은 작업은 하나로 합칩니다.
- 초상 준비 대기는 최대 800ms로 제한합니다. 시간이 지나면 본문은 이모지로 표시되며, 준비된 이미지는 다음 렌더링부터 사용합니다.
- 다른 채팅의 초상 캐시가 본문에 섞이지 않도록 문맥을 확인합니다. 상세보기 초상 수정은 유지합니다.

검증: 호스트 조회가 멈춘 조건에서 표시 100회가 추가 조회 없이 즉시 반환, 동시 준비 20회가 이미지 조회 1회로 합쳐지고 제한 시간 내 반환, 목록·상세·본문 캐시 공유 및 채팅 전환 격리 확인. 실제 운영 브라우저의 프리징 해소 여부는 별도 확인이 필요합니다.

운영 서버와 채팅 데이터는 직접 변경하지 않았습니다.

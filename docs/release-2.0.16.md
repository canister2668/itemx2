# ITEMX CODEX 2.0.16

2.0.14 이후 본문 조우 초상에 원본 Base64 이미지를 반복 삽입하던 비용을 줄였습니다. 2.0.15에 남아 있던 출력·복구·재구축의 초상 대기도 제거했습니다.

- 큰 본문 초상은 96×96 WebP 썸네일로 변환하고, 본문 이미지 문자열을 최대 24 KiB로 제한합니다. 작은 이미지 문자열은 그대로 재사용할 수 있습니다.
- 썸네일 캐시는 최대 64개이며, 본문용 준비는 원본 이미지 캐시를 채우지 않습니다. 썸네일 생성이 불가능하면 이모지를 사용합니다.
- 초상 준비는 중복 없이 비동기로 진행합니다. 출력·복구·재구축은 초상을 기다리지 않으며, 준비된 썸네일은 다음 렌더링부터 사용합니다.
- 조우 목록과 상세보기에서는 기존 원본 초상을 유지합니다.

별도 Chromium 합성 테스트: 약 264만 자의 원본 이미지 문자열을 사용하는 동일 조우 카드를 30회 렌더링할 때 원본 삽입 1,285ms, 썸네일 49ms. HTML 크기 2,638,010자에서 7,023자로 감소했습니다. 2.0.13 이모지 기준은 73ms였습니다. 단일 합성 측정으로, 실제 운영 화면의 성능 수치나 개선 배율을 보장하지 않습니다. 썸네일의 실제 디코딩 크기 96×96도 확인했습니다.

운영 서버 및 채팅 데이터는 직접 변경하지 않았습니다.

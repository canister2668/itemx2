# ITEMX CODEX 2.0.17

- 전투가 즉시 끝나도 종료된 조우는 종료 응답과 그 뒤 완료된 사용자 입력 두 번까지 조우 목록에 남습니다. 세 번째 완료 응답부터 기록에서만 표시합니다. 종료 상태를 되돌리거나 원본 사건을 삭제하지 않습니다.
- 대기 중인 입력과 스트리밍은 유예 횟수를 소모하지 않으며, 응답 삭제 시 횟수도 되돌아갑니다. 수동 보관은 즉시 적용됩니다.
- 조우 기록 목록과 상세보기에도 캐릭터·활성 모듈 에셋을 연결합니다. 기록 목록은 현재 페이지 최대 16개 썸네일만, 상세보기는 선택한 상대의 원본 초상만 읽습니다.
- 본문 디스플레이의 동기 캐시 조회 및 썸네일 크기 제한은 유지합니다. 이미지가 없거나 읽을 수 없으면 이모지로 표시합니다.

검증: 종료 직후/두 입력/세 번째 입력/스트리밍/삭제/수동 보관 회귀 테스트, 기록 두 번째 페이지와 33번째 상대 상세 초상 테스트, 기존 디스플레이 비차단 테스트. 운영 서버와 실제 사용자 채팅은 수정하지 않았으며 실사용 브라우저 확인은 별도입니다.

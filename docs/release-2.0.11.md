# ITEMX CODEX 2.0.11

- 채팅별 ITEMX 사건 원장을 고정 용량 순환 구조로 변경했습니다. 최근 24개 메시지, 96건, 192 KiB 경계 안에서 최신 원장만 유지합니다.
- 오래된 사건은 현재 인벤토리·스킬·조우 상태를 담은 봉인 체크포인트로 접고, 체크포인트 자체는 최대 512 KiB로 제한합니다.
- 체크포인트에 반영된 오래된 메시지의 ITEMX/CODEX 표시 마커와 이벤트 원장은 제거하되 일반 대화 본문은 보존합니다.
- 설정의 `저장소 최적화`에서 현재 상태를 유지한 채 최근 8개 메시지만 남기도록 즉시 정리할 수 있습니다. 완전 제거 기능과 구분되며 두 번 눌러 확인합니다.
- 채팅마다 하나씩 생성되던 보조검사 빈 결과 캐시는 최대 32개 채팅을 담는 단일 순환 저장소로 통합했습니다. 저장소 최적화 시 기존 구형 캐시 키도 제거합니다.
- 저장 한도를 넘는 비정상적으로 큰 상태에서는 장착·고정·활성 항목과 최신 항목을 우선 보존하고, UI에 저장 한도 적용 상태를 표시합니다.

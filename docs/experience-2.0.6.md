# 2.0.6 화면·기록 개선

ITEMX CODEX 2.0.6의 변경 사항과 알려진 제한입니다.

## 적용 내용

- 아이템·스킬·조우의 이전 값이 실제로 있을 때만 변경점을 표시합니다. 아이템의 이전 값은 비교에 필요한 필드만 저장하며, 기존 이벤트 재생은 이를 무시합니다.
- 스킬 상세에 검술·참격, 방어·결계, 치유, 은신·저주의 형태를 추가합니다. 명확한 이름·설명 근거가 없는 경우 기존 형태를 유지합니다. 목록에 추가 파티클은 생성하지 않습니다.
- 기존 다중속성 효과에 불/얼음의 정적인 증기 표현, 암흑/번개의 방전 영역, 불/바람의 기울기, 빛/얼음의 미세한 환경색을 적용합니다. 게임 효과나 능력치는 추가하지 않습니다.
- 강화·손상·최초 스킬 기록·교전 종료에 짧은 일회성 연출을 추가합니다. 새 출력 후보가 실제 채팅에 저장된 뒤에만 재생하고, HTML 캐시에는 재생 중 클래스를 넣지 않습니다. 재진입은 과거 연출을 예약하지 않습니다.
- 연출 대기는 최대 8개, 한 번의 DOM 확인에서 최대 2개만 재생합니다. 대기 시간 제한, 스크롤 중 보류, 문맥 전환·언로드 시 timer 및 클래스 정리를 적용합니다. 실제 DOM이 늦게 나타나면 연출은 생략될 수 있습니다.
- 상세에 메인 모델·보조 모델·수동 작업 출처, 기존 스킬 추정값, 아이템의 미해결 보완 필드를 표시합니다. 기존 자료의 출처를 추측해서 채우거나 모든 값을 확정 정보라고 표시하지 않습니다.
- 미해결 아이템 하나만 보완하는 버튼을 추가합니다. 보조 모델 1회, 해당 ID와 누락 필드만 허용하며 원문 근거에 맞지 않는 값·추가 아이템·처리 중 변경된 채팅은 저장하지 않습니다. 자동 재시도는 추가하지 않았습니다.
- 출처 정보가 없는 과거 기록에는 빈 안내를 표시하지 않습니다. 아이템 상세의 변경점·보완 안내는 카드 아래에 배치해 모바일에서 카드 폭이 압축되지 않게 합니다.
- 보조 스킬 검사는 전체 스킬 기록을 대조해 이름이 같고 유파·유형·속성이 충돌하지 않는 유일한 기존 스킬의 ID를 재사용합니다. 변화 없는 결과는 저장하지 않으며, 같은 응답의 후속 패치도 재사용한 ID로 연결합니다. 기존에 저장된 중복을 자동 삭제하지는 않습니다.

## 알려진 문제

- 아이템·조우의 보조 검사 중복 방어는 아직 미완성입니다. 같은 대상이 다른 ID로 출력되면 별도 등록될 수 있으며, 같은 ID라도 본문 카드·배너가 반복될 수 있습니다. `누락 시` 설정도 이 문제에서 예외가 아닙니다.
- 스킬의 서로 다른 이름·번역명까지 의미적으로 판별해 합치지는 않습니다. 동일 이름의 후보가 여러 개면 무리하게 병합하지 않습니다.
- 로컬 전체 회귀시험은 113개 중 112개 통과했습니다. 기존 초상화 인덱스 생성 시간 제한 시험 1개가 초과했으며, 이번 중복 방어 시험과 문법 검증은 통과했습니다. 모바일 실기 성능을 보장하는 결과는 아닙니다.

## 호환성과 비용

- 기존 marker와 compact reference를 읽을 수 있습니다. 비교값과 검토 상태는 선택적인 표시 메타데이터이며, 게임 상태·모델 프롬프트의 새 필드가 아닙니다.
- 일반 시각 처리에 추가 모델 호출은 없습니다. 사용자가 개별 보완 버튼을 누를 때만 호출합니다.
- 상세의 변경점·출처 인덱스는 필요할 때 생성합니다. 스크롤마다 채팅 조회나 인덱스 재생성을 하지 않습니다.
- 기존 기본 파티클 수는 유지합니다. 새 스킬 재질은 상세당 최대 1개 장식 노드이고, 다중속성 혼합은 CSS로 처리합니다. 추가 blur, will-change, 새 의존성은 없습니다.
- 390px Chromium의 검증용 화면에서 가로 넘침, 새 효과 OFF와 reduced-motion을 확인했습니다. 실제 RisuAI 세션의 모바일 FPS는 별도 측정하지 않았습니다.

## 확인 파일

- `dist/itemx2.plugin.js`: 설치용 파일
- `dist/experience-preview.html`: 실제 렌더러 기반 검증용 데이터 미리보기
- `dist/experience-*.png`: 모바일 폭 화면 캡처

스크린샷과 HTML을 다시 만들려면 `node scripts/preview-experience.mjs`를 사용합니다. 이 작업 환경의 브라우저 컨테이너로 화면 검증까지 실행하려면 `ITEMX_VISUAL_BROWSER=1`을 지정합니다.

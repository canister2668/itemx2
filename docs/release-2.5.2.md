# ITEMX CODEX 2.5.2

용량 한도 자동 정리를 켜고 끌 수 있게 한 버전입니다. 기록 형식은 2.5.1과 같습니다.

## 바뀐 점

- `설정 → 저장 공간`에 `용량 한도 자동 정리` 스위치를 넣었습니다. 봇마다 따로 정하며, 기본은 켜짐입니다.
  - 켜짐: 원장이 16MiB에 닿으면 다음 기록 때 자동으로 정리합니다(분기 채팅·일부만 불러온 채팅 제외).
  - 꺼짐: 자동으로 정리하지 않습니다. 16MiB를 넘으면 상태 줄이 `저장 공간 정리`를 안내합니다.
- 수동 `저장 공간 정리`는 스위치와 관계없이 그대로 쓸 수 있습니다.

# ITEMX CODEX 2.0.8 — 기록 화면 업데이트

- 전량 소모·소실된 아이템, 상실한 스킬, 종료된 조우를 현재 목록에서 분리했습니다. 우상단 `⋯ → 기록 보기`에서 확인할 수 있습니다.
- 부분 소모는 잔여 수량을 유지하며, 무기 손상이나 내구도 0만으로 목록에서 제거하지 않습니다.
- 소비가 확인된 소모품은 기본 10회 대화 완료 후 보관됩니다. OFF / 5 / 10 / 20회 설정과 개별 보존·즉시 보관을 지원합니다.
- 보관은 화면 분류이며 사건 원장이나 과거 메시지를 삭제하지 않습니다. 재획득·복귀 시 현재 목록으로 돌아옵니다.
- 기존 카드와 탭 배치를 유지하고 기록 화면을 닫으면 목록·필터·스크롤을 복원합니다.
- 로어북 설정 버튼 레이아웃을 정리했습니다.

## 같은 버전의 설치 파일 갱신

기존 `v2.0.8` 태그는 변경하지 않습니다. 이 설치 파일은 이후 `main`의 기록 화면 수정본으로 갱신되었습니다. 이미 2.0.8을 사용 중이면 버전 비교상 업데이트 알림이 나타나지 않을 수 있으므로 아래 설치 파일을 다시 가져오세요.

[설치 파일 다운로드](https://github.com/canister2668/itemx2/releases/download/v2.0.8/itemx2.plugin.js)

자동 회귀 및 모형 브라우저 레이아웃 검사를 수행했습니다. 실제 모바일 RisuAI에서의 종단간 검증과 운영 DB 적용은 이번 공개 배포에 포함하지 않습니다.

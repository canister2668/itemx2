# ITEMX CODEX 2.0.14

본문 카드가 사고문으로 이동하거나 번역 요청에서 사라지는 문제와, 조우 목록에 표시되는 초상이 상세보기에는 이모지로 나오는 문제를 수정했습니다.

- 카드 위치 검색에서 사고문을 제외합니다. reasoning·analysis 태그도 기존 사고문 보호 대상에 포함합니다.
- Risu 번역 요청에서 기존 ITEMX/CODEX 마커를 제거하지 않습니다. 번역 모델 자체가 마커를 누락하거나 변형하는 경우까지 보장하는 것은 아닙니다.
- 목록과 상세보기가 서로 다른 캐시 객체를 사용하는 경우에도 선택한 조우의 초상을 조회합니다.
- 본문 조우 카드에도 에셋 초상을 표시합니다. 대응 에셋이 없거나 조회에 실패하면 이모지를 사용합니다.
- 목록·상세보기·본문은 기존 이미지 캐시를 공유합니다.

검증: 테스트 151개 통과·1개 건너뜀. 사고문 위치 재현, 번역 요청 마커 보존, 목록 복사본과 상세보기 캐시 분리, 본문 전체·참조 마커 초상 표시와 이모지 대체 동작 검증. 서식·빌드·번들 구문 검사 통과.

운영 서버는 직접 변경하지 않았습니다. 제보 환경의 실제 번역 모델 및 운영 브라우저에서의 종단간 검증은 수행하지 않았습니다. 기존 번역 캐시에 저장된 결과는 자동으로 다시 번역하지 않습니다.

# ITEMX CODEX 2.0.13

저장소 정리 시 아이템이 사라지는 문제를 수정했습니다. 이전에는 체크포인트를 만들 때 아이템 192개, 스킬·몬스터 각 128개로 잘랐으며, 512 KiB를 넘으면 더 줄였습니다. 이제 현재 상태 전체를 보존합니다.

- 현재 아이템·스킬·몬스터의 개수 제한과 용량 초과에 따른 자동 삭제를 제거했습니다.
- 채팅의 ITEMX 저장량 16 MiB 이상에서는 경고만 표시하고 현재 상태를 보존합니다.
- 고정·보관 설정과 소모·종료 이력을 개수 제한으로 삭제하지 않습니다. 최근 이벤트에 속한 항목의 설정도 보존합니다.
- 과거 이벤트는 현재 상태에 합친 뒤 정리합니다. 최근 이벤트 원장의 24개 메시지·96건·192 KiB 기준은 유지합니다.
- 이전 버전에서 항목이 잘린 기록은 계속 표시합니다. 이미 삭제된 항목을 자동 복구하지는 않습니다.

검증: 아이템 400개 정리·재복원·수동 최적화 후 전량 유지, 16 MiB 초과 상태 직렬화·복원 시 내용 일치, 스킬·몬스터 각 200개 및 고정 설정 400개 보존. 전체 테스트 149개 통과·1개 건너뜀, 서식·빌드·번들 구문 검사 통과. 운영 사이트 및 실제 브라우저 검증은 수행하지 않았습니다.

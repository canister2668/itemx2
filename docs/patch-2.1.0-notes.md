# ITEMX CODEX 2.0.21 → 2.1.0 패치 내역 (원고)

작성용 원문. 아카라이브 게시글 HTML로 옮길 때 이 항목과 순서를 유지한다.

## 이펙트

- **속성 11종 전부 고유 연출 확보.** 기존에는 파티클만 떠다녀 속성 구분이 약했다. 속성마다 바탕 레이어를 하나씩 얹었다.
  - 화염 = 카드 하단 3겹 화염층 / 냉기 = 서리 결정·파편 / 번개 = 카드 전체 섬광 + 순간 진동
  - 맹독 = 끓어오르는 장기와 기포 / 광휘 = 위에서 내려와 바닥에 고이는 빛
  - 바람 = 돌풍 / 대지 = 퇴적 먼지 / 암흑 = 안쪽으로 잠식 / 비전 = 문양 링 / 혈기 = 바닥 고임 / 공허 = 붕괴하는 균열
- **전설급 이상 전용 연출.** 외곽 오라가 호흡하고, 테두리를 빛이 돌고, 아이템 이름이 발광한다. 하위 등급은 조용하게 유지된다.
- **낙뢰 리듬 개선.** 부드럽게 밝아지던 것을 계단식 이중 점멸로 바꿨다. 번쩍일 때 카드가 미세하게 흔들린다.
- **조우 상태 표현.** 교전 중에는 초상 주위 위협 링과 스캔선, 종결되면 채도가 빠지고 기록 낙관이 찍힌다.
- 모든 연출은 등급 강도에 연동되며, 이펙트 OFF·모션 감소 설정에서 완전히 멈춘다.

## 화면 스킨 (신규)

- **다크 · 서리 · 한지** 3종. 설정에서 즉시 전환된다.
- 서리는 밝은 중립 톤, 한지는 문서 톤. 본문 카드·인벤토리·도감·설정 전 화면에 함께 적용된다.
- 밝은 스킨에서는 카드 표면만 한 단계 낮춰 이펙트가 묻히지 않게 했다.

## UI

- **설정 재구성.** 평면 나열 16장을 연결 / 기록 / 모양 / 데이터 4개 그룹으로 묶고, 되돌릴 수 없는 작업은 별도 구역으로 분리했다.
- **조작 형태 분리.** 켜고 끄는 것은 스위치, 실행은 버튼, 셋 중 하나는 선택지가 모두 보이는 세그먼트.
- **배지 위치**를 화면 지도에서 고른다. 좌상·우중 같은 약어 대신 배지가 붙을 자리를 그대로 보여준다.
- **글자 크기**를 실제 크기로 미리 본다.
- 설명 문구를 "끄면 어떻게 되는가" 기준으로 다시 썼다.
- **본문 카드**가 아이템 카드와 같은 문법을 쓴다. 등급 프레임, 명조 이름, 그리고 변화한 수치는 `숙련 55% → 78%`처럼 이전 값을 함께 보여준다.
- 화면 권한을 받지 못한 환경의 설정 화면도 동일하게 맞췄다. 이전에는 이 환경에서 스킨을 쓸 수 없었다.

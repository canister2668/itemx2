# ITEMX CODEX 2.0.18

## 백업 · 채팅 이사

설정의 **백업 · 채팅 이사 → 저장 / 불러오기**에서 현재 아이템·스킬·조우 기록을 JSON 파일로 저장하거나 텍스트로 복사할 수 있습니다. 새 채팅에서 파일 선택 또는 붙여넣기 후 항목 수를 확인하고 불러옵니다.

- 수량·장착·효과·숙련도·조우 결과·초상 이름, 보존/보관 설정과 경과 입력 수를 유지합니다.
- ITEMX 기록이 없는 채팅에만 불러옵니다. 이미 기록이 있으면 덮어쓰지 않고 새 채팅을 안내하며, 반복 불러오기로 수량이 늘어나지 않습니다.
- 미리보기는 저장하지 않습니다. 최종 불러오기 직전 채팅을 다시 읽고, 채팅 전환·새 메시지·스트리밍을 발견하면 중단합니다.
- 대화 본문, 손요약, 다른 모듈 변수, 이미지 파일, 과거 사건 전체와 전역 설정은 포함하지 않습니다. 같은 캐릭터/모듈 에셋이 있으면 초상을 다시 연결합니다.
- 파일은 32 MiB까지 지원합니다. 외부 업로드나 모델 호출 없이 처리하며, 본문 디스플레이 경로에는 작업을 추가하지 않습니다.

[공식 API v3](https://github.com/kwaroran/RisuAI/blob/main/src/ts/plugins/apiV3/risuai.d.ts)의 getChatFromIndex/setChatToIndex/showContainer와 플러그인 iframe의 파일·Blob API를 사용합니다. [공식 factory.ts](https://github.com/kwaroran/RisuAI/blob/main/src/ts/plugins/apiV3/factory.ts)의 allow-downloads 샌드박스 설정을 확인했습니다.

검증: 세 도메인 왕복, 장착·수량·초상·기록 경과 유지, 후속 숙련도 변경과 체크포인트 압축, 중복 불러오기 차단, 잘못된 형식·위험 ID·채팅 전환·동시 수정 차단. 390px/1100px Chromium 샌드박스에서 파일 다운로드 내용 일치, 파일/붙여넣기 미리보기와 단일 저장, 가로 넘침 없음 확인. 운영 서버와 실제 사용자 채팅은 변경하지 않았습니다.

# ITEMX CODEX 2.0.5

로어북 보완의 갱신 누락과 패널 상태 문제를 수정하고, 불필요한 조회를 줄였습니다.

- 조우가 그대로여도 로어북 내용이나 활성 소스가 바뀌면 다음 자동 스캔에서 다시 확인합니다. 로어북 조회 캐시는 최대 10초간 재사용하며, 수동 새로 스캔은 캐시를 건너뜁니다.
- 보조복구로 새로 등록된 조우도 복구 이후 로어북 보완 대상으로 처리합니다.
- 삭제된 조우의 오래된 로어북 보완 기록을 정리합니다.
- 닫힌 패널의 내부 버튼 검색을 생략하고, 겹치는 패널 확인 요청을 하나로 합칩니다.
- DOM 감시가 가능한 경우와 홈 화면에서 확인 주기를 완화합니다. 감시 연결 실패 시에는 기존 폴링으로 복귀합니다.
- 조우 기능을 껐을 때 모델 요청 경로의 모듈 초상화 조회를 생략합니다.
- 소스 정렬과 CI 검사를 추가하고, 로컬 배포 도구가 ITEMX 외 설정 보존 여부를 트랜잭션 안에서 검증하도록 강화했습니다.

아이템·스킬·조우 이펙트, 저장 마커 규약과 데이터 형식은 변경하지 않았습니다. 실제 모바일 기기의 프레임 개선 수치는 별도로 측정하지 않았습니다.

설치 파일은 이 릴리즈에 첨부된 `itemx2.plugin.js`입니다. 기존 사용자는 플러그인 업데이트 후 목록의 `ITEMX CODEX · v2.0.5` 표시로 확인할 수 있습니다.

# ITEMX CODEX 2.0.10

- 모바일 브라우저에서 홈 화면으로 이동했다가 복귀하면 ITEMX 표시 정보가 사라지거나 원본 태그가 노출되던 문제를 수정했습니다.
- `pagehide`, `pageshow`, `visibilitychange`, `focus` 생명주기에서 출력·표시 처리기를 안전하게 재등록하고 최신 메시지를 다시 동기화합니다.
- 복귀 시 남아 있던 스크롤 숨김 상태와 타이머를 정리하며, 즉시 복구 뒤 보조 처리 완료 시점에 한 번 더 정합성을 맞춥니다.
- 연속으로 들어오는 복귀 이벤트는 하나의 복구 작업으로 합쳐 중복 렌더링을 막습니다.
- 저장 데이터·ITEMX 마커·아이템 상태 변환 규칙은 변경하지 않았습니다.

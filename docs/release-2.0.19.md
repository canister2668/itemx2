# ITEMX CODEX 2.0.19

백업 불러오기에 **기존 ITEMX 기록 덮어쓰기** 선택지를 추가했습니다.

- 기본값인 **빈 채팅에 불러오기**와 **기존 ITEMX 기록 덮어쓰기** 중 선택합니다.
- 덮어쓰기 미리보기에서 교체될 현재 아이템·스킬·조우 수와 백업 항목 수를 확인한 뒤 전용 버튼으로 적용합니다. 방식이나 텍스트를 바꾸면 미리보기를 다시 확인해야 합니다.
- 기존 기록, 보존/보관 설정, 이전 ITEMX 원장과 로어북 보완값을 백업 상태로 교체합니다. 빈 백업으로 빈 상태를 복원할 수도 있습니다.
- 이전 기록이 재생되어 복원 결과를 뒤집지 않도록 기존 본문의 ITEMX 카드 마커를 제거합니다. 대화 글, 다른 모듈 변수와 설정은 유지합니다. 필요하면 먼저 현재 상태를 백업하세요.
- 복원 이전 응답은 자동 보조복구로 다시 수집하지 않습니다. 이후 새 응답과 사용자가 명시적으로 요청하는 복구는 계속 처리합니다.
- 채팅 변경·스트리밍·동시 수정 방어는 덮어쓰기에도 적용합니다.

검증: 세 도메인 교체, 반복 덮어쓰기 수량 불변, 대화 글·다른 모듈 변수 보존, 오래된 원장 제거, 빈 백업 복원, 채팅 변경 차단, 자동 복구 범위, 모바일/데스크톱 방식 변경과 덮어쓰기. 운영 서버는 변경하지 않았습니다.

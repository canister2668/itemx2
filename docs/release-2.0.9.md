# ITEMX CODEX 2.0.9

- 기록을 연 뒤 인벤·스킬·조우·설정 탭으로 전환하면 목록이 공백으로 남는 문제를 수정했습니다. 부분 렌더링에서 남던 숨김 클래스를 해제하고 기록 상태와 화면을 함께 정리합니다.
- 현재 선택된 탭을 다시 눌러도 기록 화면에서 현재 목록으로 돌아갈 수 있습니다.
- `기록`과 `닫기`를 별도 버튼으로 제공합니다.
- 모델이 본문에 되풀이한 `[ITEMX v2]` 인벤토리 상태표를 출력·표시·요청 경로에서 제거합니다. 식별 가능한 상태표만 처리하며, 이를 획득·소모 이벤트로 재적용하지 않습니다.
- 명시적으로 검증된 인물명 메타데이터가 있는 정규식 로어의 조우 스캔 호환성을 포함합니다. 임의 정규식을 실행하거나 일반 로어 원문을 노출하지 않습니다.
- 저장 데이터·마커·리플레이·이펙트는 변경하지 않았습니다.
